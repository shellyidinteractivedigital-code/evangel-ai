# EVANGEL Source and Content Notice

This file records source status. It is not a substitute for the original licenses.

## World English Bible

Status: public domain. Used for starter English Scripture passages and rights-safe prototype reading.

## Open Scriptures Hebrew Bible

Role: Hebrew Bible text, lemmas, and morphology. Use only with the attribution and license terms supplied by the project.

## SBL Greek New Testament

Role: Greek New Testament source text. Use with the attribution/license terms supplied by the project.

## MorphGNT

Role: Greek morphology and lemma data. Preserve the project's attribution and share-alike obligations when incorporated.

## STEP Bible / Tyndale House resources

Role: scholarly cross-check/reference. Individual datasets can carry different terms. Verify the exact dataset before bundling or redistributing it.

## Concordant Literal Version

Role: translation comparison/reference. Treat as link/reference-only unless separate permission is obtained for in-app reproduction.

## EVANGEL-generated content

A journal entry, prayer, sermon, devotional card, comic, meme, reflection, or AI-assisted explanation does not become primary textual evidence simply because it is stored beside Scripture. EVANGEL keeps user/creative material distinct from source evidence.
