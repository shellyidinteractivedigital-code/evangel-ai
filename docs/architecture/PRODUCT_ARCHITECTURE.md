# EVANGEL Product Architecture

EVANGEL is one connected faith workflow with two deliberately different information paths.

## Evidence path: EVANGEL Scholar

Scholar answers textual and translational questions. It should make the source chain visible and distinguish what the text says from what a translator, commentator, devotional writer, or user concludes.

## User-work path: Spatial Studio

The Spatial Studio contains material deliberately saved or created by the user: verses, notes, journals, highlights, prayers, studies, sermons, collections, voice notes, and future creative cards.

User-created material may be meaningful and theologically rich, but it does not silently become evidence for a Greek, Hebrew, manuscript, or translation claim.

## Organizing hub: 3D Faith Space

The 3D Faith Space is a memory layer over canonical saved items. A saved object should remain the same logical object when opened from Library, Journal, Study, Creator, or the spatial scene.

## Drive Mode

Drive Mode is a narrower EVANGEL: listen, ask, repeat, next, save. Long reading, typing, configuration, and visually complex study do not belong in motion mode.

## Connected flow

A moment can travel naturally:

`Listen -> Save -> Study -> Scholar -> Journal -> Creator -> Faith Space`

The user should not need to reconstruct context at each step.
