# EVANGEL Runtime Assets

Store only optimized images and other binaries required by the running website/app here.

Do not use this folder as an archive for historical ZIP builds, duplicate PDFs/DOCX files, raw generated-image batches, or publication packages. Put distributable bundles in GitHub Releases or another release/document store instead.

Before adding a large binary, ask whether it can be optimized or regenerated from source. Use Git LFS only when the binary must be versioned with the repository.
